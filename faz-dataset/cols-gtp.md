# `$log-gtp` — GPRS Tunnelling Protocol

GTP is a telecommunications protocol used for carrying mobile data in cellular networks (GSM/UMTS/LTE). These logs are generated by FortiGate devices acting as GTP gateways or proxies.

All common columns apply where relevant (see cols-common.md).

| Column | Type | Description |
|---|---|---|
| `status` | Nullable(String) | GTP session status |
| `version` | Nullable(String) | GTP protocol version |
| `profile` | Nullable(String) | GTP inspection profile name |
| `type` | Nullable(String) | GTP message type |
| `subtype` | Nullable(String) | GTP message subtype |
